# Dial Micrometer Deflection Simulator — PWA

PWA πακέτο βασισμένο στο HTML αρχείο `dial_micrometer_demo_v12_smooth_190_start.html`.

## Περιεχόμενα

- `index.html` — κύρια εφαρμογή PWA
- `manifest.webmanifest` — PWA manifest
- `sw.js` — service worker για offline cache
- `offline.html` — offline fallback
- `icons/` — PWA icons
- `source/` — το αρχικό HTML αρχείο που χρησιμοποιήθηκε ως βάση
- `.nojekyll` — για GitHub Pages

## GitHub Pages

1. Ανέβασε όλα τα αρχεία στο root του repository.
2. Πήγαινε **Settings → Pages**.
3. Source: **Deploy from branch**.
4. Branch: `main`, folder: `/root`.
5. Άνοιξε το URL του GitHub Pages.
6. Από Chrome/Edge επίλεξε **Install app** ή **Add to Home Screen**.

## Σημείωση

Για PWA install/offline απαιτείται HTTPS ή localhost. Το GitHub Pages παρέχει HTTPS.
